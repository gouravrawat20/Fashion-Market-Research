# Fashion Market Research & Data Analysis

## Project Overview
This project focuses on market research in the Apparel, Textiles and Fashion industry. It analyses 60 selected products from five globally recognised fashion brands.

## Brands Covered
- Hermès
- Louis Vuitton
- Chanel
- Zara
- Nike

## Project Objectives
- Study fashion brand product ranges and pricing.
- Understand target customer demographics.
- Clean and organise product data.
- Analyse product categories and brand distribution.
- Identify business insights using Excel.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Charts
- Data Cleaning and Analysis

## Project Workflow
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights
6. Report Writing

## Key Findings
- Handbags are the most represented product category in the sample.
- Women-targeted products have the highest representation.
- Hermès has the highest average sample price.
- The dataset contains 60 product records across five brands.

## Project Files
- Fashion Market Research Report.xlsx
- Fashion_Market_Research_Week1_Report.docx

## Note
This project uses a selected sample of 60 product records. Prices and target demographics are indicative research data and should not be considered a complete representation of each brand's catalogue or actual customer base.
